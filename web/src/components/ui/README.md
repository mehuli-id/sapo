# Komponen UI

Komponen di folder ini disalin dari [shadcn-vue](https://github.com/unovue/shadcn-vue) (gaya `new-york-v4`, commit `de1f76c`), sesuai pendekatan shadcn: kode komponen menjadi milik proyek dan boleh diubah. Lisensi asli: MIT (lihat `LICENSE-shadcn-vue.txt`), kompatibel dengan GPL-3.0.

Untuk menambah komponen baru: `npx shadcn-vue@latest add <nama>` dari folder `web/`, atau salin dari repo shadcn-vue lalu ganti import `cn` menjadi `@/lib/utils`.
