# ADR 0023: Wi-Fi

- **Status:** Diterima
- **Tanggal:** 2026-10-26

## Konteks

Sapo dipasang di komputer bekas dan laptop, dan banyak laptop tidak punya port LAN. Sampai sekarang hanya antarmuka kabel yang bisa diatur (ADR 0009), dan firmware Wi-Fi tidak ada di ISO. Ada juga masalah ayam dan telur: tanpa jaringan, panel tidak bisa dibuka untuk mengatur Wi-Fi.

## Keputusan

- **WPA2/WPA3 Personal saja** (password 8–63 karakter ASCII). Jaringan terbuka dan Enterprise (802.1X) tidak bisa dipilih: tanpa enkripsi, lalu lintas SMB dan password Samba bisa disadap tetangga.
- **Diatur seperti antarmuka kabel** (`network.apply`, ADR 0009): nama host, DHCP atau alamat tetap, konfirmasi dari panel, dan pengembalian otomatis. Salah password Wi-Fi tidak membuat NAS terputus selamanya.
  - Antarmuka nirkabel (`/sys/class/net/<x>/wireless` atau `phy80211`) yang tidak disebut tidak dipakai (kabel yang tidak disebut tetap DHCP).
  - Antarmuka Wi-Fi yang dipakai wajib punya jaringan; `wifi` di antarmuka kabel ditolak.
- **File wpa_supplicant per antarmuka** (`agent.network.wpa_conf_dir`/`sapo-<x>.conf`, 0600 root), dirujuk `/etc/network/interfaces` lewat `wpa-conf` (integrasi ifupdown paket `wpasupplicant`).
  - SSID dan password ditulis **heksadesimal** (`ssid=`, `sae_password=`); PSK WPA2 dihitung `sapod` (PBKDF2-SHA1, 4096 putaran). Tidak ada tanda kutip atau teks dari panel yang bisa menambah baris atau blok `network={}`.
  - `key_mgmt=WPA-PSK WPA-PSK-SHA256 SAE`, `ieee80211w=1`: router WPA2, WPA3, dan campuran. `scan_ssid=1`: jaringan tersembunyi juga bisa.
  - `country=` dari `agent.network.wifi_country` (bawaan `ID`), agar kanal dan daya pancar legal.
  - File itu ikut disimpan dan dikembalikan bersama file jaringan lain selama menunggu konfirmasi, selalu dengan mode 0600. Antarmuka yang dimatikan menghapus filenya (password lama tidak disimpan lagi).
- **Password tidak pernah keluar dari `sapod`.** Panel dan menu konsol hanya mengirim password. `network.status` (pengaturan dan perubahan yang menunggu) dan log audit memakai `NetworkConfig.Redacted()`. Password kosong berarti tetap memakai password tersimpan untuk SSID yang sama.
- **Pindai** (`network.wifi_scan`): antarmuka dinyalakan tanpa alamat, lalu `iw dev <x> scan` (atau `scan dump` bila sedang sibuk). Hasilnya: sinyal terkuat per SSID, maksimal 50, dan tanda apakah bisa dipakai (PSK/SAE). Keadaan sambungan (SSID, sinyal) lewat `iw dev <x> link` di `network.status`.
  - **Pengecualian `--`**: `iw` menolak `--` sebagai pemisah opsi, jadi `sapod` memanggilnya lewat `runToolArgs` tanpa `--`. Satu-satunya argumen dari luar adalah nama antarmuka, yang harus cocok dengan pola nama, tidak berawal `-`, dan benar-benar antarmuka nirkabel di sysfs.
- **Menu konsol "Sambungkan Wi-Fi"** (ADR 0008, layar dan keyboard NAS): untuk komputer tanpa kabel LAN.
  - Pilih kartu (bila lebih dari satu), pindai, pilih jaringan atau ketik nama jaringan tersembunyi, lalu ketik password tanpa gema di layar.
  - Menu memanggil operasi `sapod` yang sama dengan panel lewat socket `sapod` (root).
  - Bila dalam 90 detik antarmuka tersambung ke SSID itu dan mendapat alamat IPv4, menu mengonfirmasi sendiri dan menampilkan alamat panel. Bila tidak, perubahan dibatalkan sekarang juga (`network.cancel`).
  - Tercatat di log audit (`recovery.wifi`, SSID tanpa password).
- **Reset jaringan dari menu darurat** mematikan Wi-Fi (`inet manual`): tanpa jaringan, DHCP-nya hanya menunda boot. Wi-Fi disambungkan lagi lewat menu.
- **Paket**: `wpasupplicant`, `iw`, `wireless-regdb` di fitur inti; firmware `firmware-iwlwifi`, `firmware-atheros`, `firmware-brcm80211`, `firmware-mediatek` (Realtek sudah ada di `firmware-realtek`) di ISO. Installer ikut menyalin `/etc/wpa_supplicant`.

## Akibat

- NAS tanpa kabel bisa dipasang dan dipakai; kabel tetap disarankan karena lebih cepat dan stabil.
- Belum ada: Wi-Fi Enterprise, beberapa jaringan cadangan per antarmuka, dan NAS sebagai hotspot.
- Uji: unit test (vektor PSK IEEE 802.11i, file heksadesimal tanpa password apa adanya, SSID dengan baris baru ditolak, password tidak bocor di status dan audit, file 0600 dikembalikan saat batal, parser `iw`, alur menu konsol berhasil dan gagal). File buatan `sapod` dibaca `wpa_supplicant` Debian 13 tanpa galat (SSID, PSK, `sae_password`, `key_mgmt`). Uji asap ISO: menu "Sambungkan Wi-Fi" menjawab lewat `sapod` di VM tanpa kartu Wi-Fi. `tools/wifi-hwsim/run.sh` menyambungkan file buatan `sapod` ke titik akses `hostapd` WPA2 dan WPA3 lewat radio virtual kernel (`mac80211_hwsim`), memeriksa parser `iw` dengan keluaran sungguhan, dan memastikan password salah ditolak. Skrip ini dijalankan manual, karena kernel runner CI tidak punya modul itu. Kartu Wi-Fi sungguhan diuji manual di laptop.
