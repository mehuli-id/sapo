# Panduan brand (draf)

Identitas visual Sapo masih tahap awal. Logo di `web/public/brand/` dan komponen `SapoLogo.vue` adalah logo **sementara**: atap lumbung *sapo page* bergaya garis.

Yang akan diisi di sini:

- logo final (versi warna, monokrom, ikon aplikasi),
- palet warna (OKLCH, sama dengan `branding.yaml`),
- tipografi dan gaya ikon aplikasi,
- aturan pemakaian nama dan logo untuk komunitas (lihat juga `TRADEMARKS.md`).
