# Kebijakan Keamanan

Sapo menyimpan data penting pengguna, jadi laporan celah keamanan kami tangani dengan serius.

## Melaporkan celah

**Jangan laporkan celah keamanan lewat issue publik.**

Gunakan fitur *Report a vulnerability* (GitHub Security Advisories) di halaman repo ini. Sertakan:

- versi Sapo dan cara memasang,
- langkah untuk mereproduksi,
- dampak yang Anda perkirakan.

## Yang bisa Anda harapkan

| Tahap | Target waktu |
|---|---|
| Konfirmasi laporan diterima | 3 hari kerja |
| Penilaian awal tingkat keparahan | 7 hari kerja |
| Perbaikan untuk celah kritis | secepatnya, target 30 hari |

Setelah perbaikan dirilis, kami menerbitkan advisory publik (dan CVE bila relevan) serta mencantumkan nama pelapor bila diizinkan.

## Versi yang didukung

Sapo masih pra-alpha. Perbaikan keamanan hanya diberikan untuk branch `main` sampai rilis stabil pertama.
